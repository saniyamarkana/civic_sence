What is BFS?

Breadth-First Search (BFS) is a graph traversal algorithm that explores nodes level by level — visiting all neighbors at the current depth before moving deeper. It uses a FIFO Queue (First-In, First-Out).

  • Visits Root Node first (Level 0)
  • Then all Level-1 children left to right
  • Then Level-2 grandchildren, and so on
  • Guarantees shortest path in unweighted graphs

Complexity Analysis

For a Binary Tree with V vertices and E edges:

  • Time Complexity: O(V + E)
  • Space Complexity: O(V) — for the queue
  • In this tree: V = 9 nodes, E = 8 edges
  • BFS explores all 9 nodes in exactly 9 dequeue steps

BFS Pseudocode

BFS(graph, start):
  visited = []
  queue = Queue()
  queue.enqueue(start)
  visited.add(start)

  while queue not empty:
    node = queue.dequeue()   ← FRONT
    process(node)

    for each neighbor of node:
      if neighbor not in visited:
        visited.add(neighbor)
        queue.enqueue(neighbor)

Binary Tree Structure

A Binary Tree is a hierarchical structure where each node has at most 2 children — a Left Child and a Right Child.

  • Root: Central Zone (Chowk) — Level 0
  • Internal nodes: Levels 1 & 2 — have children
  • Leaf nodes: Level 3 — no children
  • Height: 3 (longest root-to-leaf path)
  • Width: 4 nodes at Level 2 (widest level)
Property BFS (Breadth-First) DFS (Depth-First)
Data Structure Queue (FIFO) Stack (LIFO) / Recursion
Traversal Order Level by level (horizontal) Branch by branch (vertical)
Time Complexity O(V + E) O(V + E)
Space Complexity O(V) — stores entire level O(h) — h = tree height
Shortest Path ✓ Guarantees shortest path ✗ Not guaranteed
Best for Nearest neighbors, level-order Path finding, topological sort
